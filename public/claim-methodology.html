Claim Methodology

Version 1.0 · Published 1 August 2026 · EcoGreen360 Oy

Every figure ECO360 produces is labelled with the method that produced it — Measured, Derived or Estimated — and with the data source or factor set used. This page explains what those labels mean and how the calculations work.

1. The three-tier system

Every CO₂ figure carries exactly one tier label. A figure can only carry the tier of its weakest input — a Measured primary emission calculated using a grid factor that is Derived produces a Derived result, not a Measured one.

TierWhat it meansTypical source
Measured Based on a supplier-submitted or manufacturer-published Product Carbon Footprint (PCF) document, verified for method and version. Apple Environmental Progress Report, Dell Product Carbon Footprint, manufacturer PCF database
Derived Calculated from a primary activity figure (kWh, km, kg of material) using a published emission factor. The factor version and source are recorded at calculation time. IEA World Energy Outlook electricity factors, AIB European Residual Mixes, EU EF 3.1 material factors
Estimated Produced by the mass-estimation cascade when primary data is unavailable — a statistical proxy drawn from products in the same item-group or HS code class. Carries the widest uncertainty band. ECO360 internal product database, median mass by item group

2. Uncertainty bounds

Every figure carries a P5–P95 uncertainty interval, not a point estimate. We do not report uncertainty narrower than ±20 % (1σ) at any tier — this matches the MIT PAIA model used by Dell, HP and Lenovo for their own published PCF numbers, whose P5–P95 spread on a single laptop model is approximately 3.5×.

TierMinimum σ (relative)Source of additional uncertainty
Measured±5 %Manufacturer methodology variation, functional unit boundaries
Derived±15 %Factor vintage, grid mix vs. residual mix, mass estimation error
Estimated±30 %Mass proxy accuracy, item-group heterogeneity, factor applicability

Uncertainty contributions from independent sources are combined in quadrature: σ_total = √(σ_factor² + σ_mass²).

3. Emission factor sources

Factors are versioned and dated. A calculation result records the factor set version used at the time of calculation. Factors are never back-applied to existing results when a new version is published.

4. Scope boundary

Unless stated otherwise, a device CO₂ figure covers cradle-to-gate manufacturing (Scope 3, Category 1: purchased goods and services). Use-phase electricity consumption is calculated separately and reported as Scope 2 when a grid factor is available. End-of-life (Category 12) is reported separately using Eurostat EU-average treatment shares when primary data is absent.

We do not aggregate Scope 1, 2 and 3 into a single number. A single-number "carbon footprint" across all three scopes combines quantities that are typically double-counted in supply chains and should not be summed without an explicit methodology statement naming the double-counting convention used.

5. Reproducibility

Every workbook produced by the ECO360 pipeline records:

  • A unique run ID
  • The factor set version used at calculation time
  • The source profile version (column mapping and sentinel conventions)
  • A SHA-256 hash of the input file
  • The as-of date for all time-dependent lookups (grid factors, substance lists)

Given the same input file and factor set version, the ECO360 engine produces bit-identical output. This is verified by an automated reproducibility test that is part of the CI suite on every code change.

6. Claims we do not make

  • We do not describe any product as "sustainable", "green" or "eco-friendly" — these are unsubstantiated claims under EU Directive 2024/825/EU (Green Claims Directive). We report numbers; we do not assign rankings.
  • We do not use percentage comparisons ("X% less CO₂") without naming the reference product, its CO₂ figure, and its tier — comparisons between figures at different tiers are not published.
  • We do not issue regulatory clearance for REACH, RoHS, TSCA or Prop 65. A legal determination of conformity with those regulations requires a qualified person with full access to the Bill of Materials. Our substance screening identifies risk — it does not establish legal status.

7. Updates and corrections

When an error is found in a published figure, we:

  • Publish the corrected value with the correction date and a description of what changed
  • Retain the original value in the calculation history with a correction note
  • Do not silently overwrite historical results

To report a potential error, email data@eco360.ai with the product name, the figure in question, and the source you believe is more accurate.
